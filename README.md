**Zero-Day Malware Behavior Detection**

An academic, safe malware behavior detection workflow using a synthetic, feature-only behavioral dataset. Trains and compares Logistic Regression, Random Forest, Extra Trees, and Gradient Boosting classifiers, then simulates a zero-day scenario by holding out an entire malware family (`rootkit`) from training to test generalization on unseen threats. Built independently.

| Stack | Scale | Impact |
|---|---|---|
| Python, scikit-learn, Pandas, NumPy, Matplotlib | 4-model comparison pipeline with full evaluation suite | Simulates zero-day detection via holdout-family testing; outputs classification reports, confusion matrices, ROC curves, and feature importance |

🔗 [View Repository](https://github.com/arch-zain/Fingerprint-based-zero-day-threat-classification)

</details>
